# スモチャン -Sumo Champions- 結婚式Ver

日野錦さんの結婚式ウェルカムスペースで稼働させるための特別バージョンです。
通常版（[Sumo-Champions](https://github.com/Leon-N-45/Sumo-Champions)）Ver.19.9.8 から分岐しています。

通常版とは**別のスプレッドシート**を参照し、**別リポジトリ**で管理します。通常版へは戻しません。

## 最初にやること

### 1. 参照スプレッドシートの切り替え（必須）

現在、参照先が**通常版のスプレッドシートのまま**です。このまま数値を調整すると通常版に影響します。

1. 通常版のスプシを「ファイル > コピーを作成」で複製
2. 「ファイル > 共有 > ウェブに公開」で CSV 公開
3. 公開URLに含まれる `2PACX-...` を [`js/config.js`](js/config.js) の `SHEET_ID` に貼り替え

切り替えが済むまで、起動時にブラウザのコンソールへ警告が出ます。

```js
// js/config.js
const SHEET_ID = NORMAL_SHEET_ID;  // ← ここを新しいIDに差し替える
```

## 起動

`index.html` をブラウザで開くだけです。タイトルバーと画面下部に「結婚式Ver」と表示されるので、通常版と取り違えないか確認してください。

## 開発ロードマップ

### 最優先（当日の事故要因）

- [ ] **オフライン化** — 現状、起動時にスプシ取得が終わるまでゲームが始まらない。取得失敗時のフォールバックもタイムアウトも無いため、会場の通信環境に依存すると詰む
  - データをローカルの JS ファイルに焼き込む（`file://` で開く場合、ローカル JSON の `fetch` はブラウザに拒否されるため `<script>` で読む形式にする）
  - Google Fonts も CDN 取得しているので同梱する
- [ ] **「戻る」のフルリロード廃止** — `location.reload()` のため、ゲスト一組ごとにページとCSV取得がやり直しになる
- [ ] **コントローラ対応の確認** — キーボード入力のみ対応（1P=WASD / 2P=矢印）。アーケード用USBエンコーダの多くはゲームパッドとして認識され無反応になる

### ゲーム内容

- [ ] ドリーム力士の非表示化（解放用の隠しコマンドごと削除する）
- [ ] 空いた枠に日野さん・奥さまを追加
- [ ] 四股名を通常のものに戻す
- [ ] 新郎新婦らしい体表示（紋付・白無垢／ドレス）
- [ ] 熱海富士を追加（祖母希望）
- [ ] 朝青龍を追加（高校友達）
- [ ] タイトル・結果画面を結婚式Verに
- [ ] ルールの単純化（溜め操作の自動化／いなし廃止／一番勝負／CPU弱め）
- [ ] BGMの選定・追加（和風Ver、日野歌唱は無し）
- [ ] 四股名ボイスの再録（`assets/se/hino.mp3` は既存。奥さま・熱海富士・朝青龍分が必要）

### 運用まわり

- [ ] 無操作時にタイトルへ自動復帰する処理（結果画面からの5秒復帰は実装済み）
- [ ] 設定画面へ入られないようにする
- [ ] 音量の初期値を会場想定で保存しておく

## ディレクトリ構成

```
.
├── index.html        # エントリーポイント
├── manual.html       # 操作マニュアル
├── css/              # base / ui / battle / team
├── js/
│   ├── config.js     #   設定値・定数・スプシ参照先
│   ├── data.js       #   外部CSVの読み込み・適用
│   ├── audio.js      #   BGM・SE・ボイス
│   ├── player.js     #   力士のステータス・状態
│   ├── ai.js         #   CPU思考
│   ├── game.js       #   個人戦の進行・物理演算
│   ├── ui.js         #   個人戦の画面表示
│   ├── team_game.js  #   団体戦の進行
│   ├── team_ui.js    #   団体戦の画面
│   └── settings.js   #   音量・キーコンフィグ
└── assets/           # img / fonts / bgm / se
```
